# Compute 50 (front end)
    npm install
    npm run dev      # local preview
    npm run build    # production build in /dist

Edit placeholder content in the `D` object and `START` / `FEE` at the top of `src/App.tsx`.
Set `LOGO` to a path in `/public` to show your event logo. Auth, team and payment are mocked
in the `Auth` and `Profile` components: connect your API there.
